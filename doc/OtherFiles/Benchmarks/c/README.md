# C benchmark code
Benchmark done using [ubench](https://github.com/sheredom/ubench.h).

To run it install ubench on your machine, copy `benchmark.c` on ./sphincsplus/ref from the [official c implementation](https://github.com/sphincs/sphincsplus)
and copy benchmark.fish on ./sphincsplus

To run it use `fish benchmark.fish`

You need [fish shell](https://fishshell.com/) to run it.
